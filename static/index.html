Core Features

Everything you need to operate Telegram at scale

Built on Telethon MTProto — the same native protocol Telegram uses. All operations run server-side, keeping your devices and credentials safe.

🚀

Mass Autojoin

Join hundreds of Telegram channels and groups in bulk using multiple accounts simultaneously. Paste a list of t.me links — the platform queues them as a durable background job, handles flood-wait errors automatically, and reports each result. Supports round-robin rotation across accounts.

🔍

Member Scraper

Extract member lists from any public group or channel you have access to. When a channel hides its participant list, the platform falls back to scanning recent messages to collect unique active members — so you still get results even on privacy-restricted groups.

📋

Bulk Target Scraping

Process multiple scrape targets in a single run. Paste one channel or group per line — Apify-style — and the platform scrapes all targets in sequence, combining results or delivering per-target exports. Ideal for competitor research and audience building at scale.

📢

Bulk Message Sender

Send personalised or broadcast messages to lists of users across your connected accounts. Supports scheduling, rotation mode (spread load across multiple accounts), and per-message delay tuning to stay within Telegram's rate limits.

👤

Account Manager

Onboard and manage multiple Telegram accounts in one place. Each account connects via secure MTProto session files encrypted at rest. Monitor account health, session status, and connectivity — no need to keep a device logged in.

📅

Scheduler

Schedule recurring tasks — joins, outreach runs, scrape jobs — to run automatically at set times. The scheduler persists across deployments, ensuring your automation continues uninterrupted even after updates or server restarts.

📊

Job Progress Tracker

Every background operation (autojoin, bulk send, scrape) is tracked as a durable job with real-time status. See queued, running, completed, and failed counts. Expand any job card to inspect per-link results with timestamps and error reasons.

🤖

MCP / AI Agent Tools

Expose platform capabilities as MCP (Model Context Protocol) tools for AI agents. Automate complex workflows by connecting open-teleset to Claude, ChatGPT, or any agent framework — with built-in auth, rate limiting, and audit logging.

How It Works

From setup to running in minutes

open-teleset runs entirely on your own infrastructure. Your Telegram sessions never leave the server.

1

Add Accounts

Connect your Telegram accounts via phone + OTP. Sessions are encrypted and stored server-side.

2

Pick a Tool

Choose Autojoin, Scraper, Bulk Send, or Scheduler from the dashboard navigation.

3

Configure & Run

Paste your targets, set options, and click Run. Jobs execute in the background — no browser tab required.

4

Monitor Results

Track live progress in the Job Tracker. Download exports or pipe results into the next step.

Platform Guide

Every section, explained

A quick reference for each part of the dashboard.

Autojoin — Mass channel & group joining

Paste multiple Telegram links (one per line) and join them all across one or many accounts. The job runs in the background — you can close the browser and results will still be tracked.

  • 1
    Select Account or enable Rotation Mode to spread joins across multiple accounts and avoid flood-wait errors.
  • 2
    Paste your links in the Target URLs textarea — one t.me link per line. Supports t.me, telegram.me, telegram.dog
  • 3
    Set Delay (seconds) between joins (recommended: 30–60s) and an optional Per-run cap (0 = unlimited).
  • 4
    Click Queue Join Job. A durable background job is created — progress appears in the Job Tracker below.
  • 5
    Expand any job card in the Progress Tracker to see per-link outcomes: joined, already-member, skipped, or failed with reason.

Scraper — Extract member lists from channels

Collect the user list from any channel or group you have access to. If the member list is hidden, the platform automatically falls back to scanning recent messages.

  • 1
    Select the Account that is a member of the target group/channel.
  • 2
    Enter one or more targets in the Target field — one per line for bulk scraping. Bulk mode
  • 3
    Click Pick from Groups to browse groups the selected account has joined, or type the channel username directly.
  • 4
    Click Scrape Members. The scrape_mode in the result will show participants (full list) or messages_fallback (hidden-members mode).
  • 5
    Download the member list or use it as input for Bulk Send or Member Adder.

Bulk Send — Send messages to user lists

Send a message to a list of Telegram user IDs or usernames. Supports account rotation and configurable per-message delays to stay within Telegram rate limits.

  • 1
    Paste User IDs or usernames — one per line — into the recipients field.
  • 2
    Write your Message (supports basic Telegram markdown formatting).
  • 3
    Select a Sender Account or enable Round-Robin Rotation across multiple accounts.
  • 4
    Set Delay between sends. 20–45 seconds is typical for safety; lower values risk flood-wait.
  • 5
    Click Send. Progress tracks in real time with sent / failed counts per account.

Accounts — Manage connected Telegram accounts

Add, monitor, and control the Telegram accounts that power all platform operations. Sessions are stored encrypted on the server — no active device required after login.

  • 1
    Click Add Account and enter your phone number. A one-time Telegram OTP code will be sent to your device.
  • 2
    Enter the OTP code (and 2FA password if enabled). The session is saved server-side, encrypted at rest.
  • 3
    The account appears in the list with its Telegram username, ID, and session status.
  • 4
    Use Deactivate to pause an account without deleting the session, or Remove to permanently delete it.
  • 5
    Accounts flagged with error status have a session that needs re-authentication — click to refresh.

Scheduler — Automated recurring tasks

Create scheduled runs that execute automatically on a cron-like schedule. Schedules persist across deployments and server restarts via persistent storage.

  • 1
    Click New Schedule and select the task type: Autojoin, Bulk Send, or Scrape.
  • 2
    Configure the task parameters exactly as you would in the manual tab.
  • 3
    Set the Schedule: daily, hourly, or a custom cron expression.
  • 4
    Toggle Active to enable. The scheduler fires the task at the configured interval even if the dashboard is not open.
  • 5
    Past runs appear in the schedule history with status and result counts.

Member Adder — Add users to your groups

Add a list of users to a Telegram group or channel you administrate. Typically used after scraping members from a source group.

  • 1
    Select the Account that is an admin of the target group.
  • 2
    Use Pick from Groups to select the destination group, or type its username.
  • 3
    Paste the User IDs to add — one per line. These are typically exported from the Scraper.
  • 4
    Set a Delay between adds (30s+ recommended). Telegram rate-limits group add operations heavily.
  • 5
    Click Add Members. Results show added, already-member, privacy-blocked, and failed counts.
